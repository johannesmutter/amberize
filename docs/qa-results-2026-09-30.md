## Confirmed findings during actual QA

Native macOS reopening failed after the main window had been released: opening the running application through macOS produced no window, while starting a second executable reopened it. The missing `RunEvent::Reopen` handler was added. The same background process subsequently reopened its window successfully; normal Quit also succeeded.

QA exposed a mistake in the earlier workflow repair: Cargo's `--locked` flag was passed as a Tauri option, which aborted all installer builds. The failure was reproduced locally and the argument moved after `--`. MSI packaging also rejected the `rc.5` label; the isolated candidate now uses an MSI-compatible numeric prerelease version. The complete builder then exposed mismatched JavaScript and Rust Tauri versions after the dependency refresh. The API, dialog, and updater packages now match the locked Rust versions, and the full local Tauri release build passed with the corrected invocation.

Recovery and missing-password messages exposed internal parser and credential-reference details. They now explain what happened and point to Settings. Native rendering verified those messages. A long error message also overlapped the archive statistics; it now truncates within its available width while its full text remains available in the tooltip.

Export checkboxes were nested inside a control with the button role, so macOS accessibility exposed the row as one preview button. The checkboxes and preview buttons are now separate native accessibility controls. Selection instructions match the checkbox interaction. The native app successfully selected and exported exactly one message after the fix.

After Apple authentication and agreement access were repaired, both Mac build jobs passed the app checks. Independent download checks found a further real packaging defect: the signed DMG containers were rejected by Gatekeeper as `Unnotarized Developer ID`, while their contained apps passed. The release workflow had only notarized and assessed the app. It now also submits the signed DMGs to Apple, requires `Accepted`, staples their tickets, validates the signatures and tickets, and assesses the containers before replacing the draft assets. Both existing DMGs were repaired without rebuilding or changing the app executables or updater packages. Apple recommends notarizing the outermost distributed container in [Packaging Mac software for distribution](https://developer.apple.com/documentation/xcode/packaging-mac-software-for-distribution).

Some WebKit or system helpers remained after the UI was closed.

These are physical-footprint observations with a 1,024-message fixture on a memory-compressed Mac under Rosetta. They are not a sustained-sync benchmark, a native Apple Silicon measurement, or proof that long-running memory cannot grow. An initial direct child launch inherited Codex's resource coalition and counted unrelated processes; that measurement was excluded, and the helper now refuses measuring its own coalition.

The memory helper groups processes by the app's resource coalition, using the ABI documented in [Apple's XNU source](https://github.com/apple-oss-distributions/xnu/blob/main/bsd/sys/proc_info_private.h), and records physical footprint including compressed pages. RSS alone substantially understated memory on this host. Process membership, final-build cycles, and installer results are recorded in [qa-evidence-2026-09-30.json](qa-evidence-2026-09-30.json).
